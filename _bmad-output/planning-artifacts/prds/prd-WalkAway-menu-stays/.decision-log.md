# Decision log — Menu bar icon stays

Created: 2026-08-31
Status: final

## 2026-08-31 — Fast path

- **Decision:** Do not reload Preferences until `isViewLoaded`. Rebuild the device popup through `NSMenu.addItem`, never `item(at:)` on a menu that has fewer items than the device list. Keep creating the Preferences controller at launch so the window can still appear.
- **Source:** Ferenc, 2026-08-31: a few seconds after 0.1.4 launch the menu icon disappears. Crash: `reloadDevicePopup` → `NSMenu itemAtIndex:` after BLE `didDiscover`.
- **Landed in:** FR-1, FR-2, `deviceMenuRows`.
