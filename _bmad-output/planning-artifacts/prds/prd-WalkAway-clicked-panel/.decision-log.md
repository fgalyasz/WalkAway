# Decision log — Clicked panel is the one that opens

Created: 2026-08-31
Status: final

## 2026-08-31 — Fast path

- **Decision:** Do not open panels from `menuDidClose`. macOS can send `menuDidClose` before the item action, so that path presents the previous click. Call the matching `open*` from the item action on the next run loop (`perform afterDelay: 0`). `PanelActivation` still places and orders the window front.
- **Source:** Ferenc, 2026-08-31: About does not open; the next Preferences click opens About; the next About click opens Preferences.
- **Landed in:** FR-1, FR-2.
