# Decision log — Auto-install updates

Created: 2026-09-03
Status: final

## 2026-09-03 — Fast path

- **Decision:** Add Sparkle `SUAutomaticallyUpdate` / `automaticallyDownloadsUpdates`, exposed as Preferences **Install updates automatically**, default **on**. When on: download and replace without Install; Sparkle’s relaunch prompt is allowed. When off: keep today’s confirm-Install flow. Check interval stays Sparkle’s 24h default. Same contract as SnappyZones and SessionGuard (menu checkbox where there is no Preferences window).
- **Rationale:** Ferenc asked to plan auto-install so the process can finish without an Install click. WalkAway already has Preferences with Launch at Login. Default on matches wanting no routine human step.
- **Rejected:** Always-on with no toggle. Fully silent relaunch with a custom user driver in v1. Putting the switch only in the status menu (Preferences is the home for Launch at Login).
- **Source:** Chat 2026-09-03 after Sparkle interval discussion.
- **Landed in:** PRD, addendum.
