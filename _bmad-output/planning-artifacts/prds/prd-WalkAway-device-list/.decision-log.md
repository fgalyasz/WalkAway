## 2026-08-31 — Fast path

- **Decision:** Sort menu rows by name then id. Do not reload the popup while its menu is tracking. BLE updates refresh devices only after the menu closes, and do not rewrite sliders.
- **Source:** Ferenc, 2026-08-31: list order jumps with RSSI; a click almost never selects the intended row.
- **Landed in:** FR-1, FR-2, `sortedDevicesForMenu`, `shouldReloadDeviceMenu`.
