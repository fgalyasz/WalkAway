# Decision log — WalkAway foundation

Created: 2026-08-31
Status: final

## 2026-08-31 — Fast path

- **Decision:** New TenPrint product, not a SessionGuard feature. SessionGuard keeps a session awake. WalkAway locks when the user leaves. Same catalog family, separate binary.
- **Source:** Ferenc, 2026-08-31 chat.
- **Landed in:** PRD vision, FR-1.

## 2026-08-31 — Stack

- **Decision:** Swift + AppKit menu bar, testable Core target. Not Python. CoreBluetooth and screen lock are first-class on this stack.
- **Source:** Fast path. SnappyZones is the style template.
- **Landed in:** addendum, repo layout.

## 2026-08-31 — v1 scope

- **Decision:** Lock on walk-away. Do not sleep the Mac. Do not auto-unlock. Apple Watch or iPhone via BLE. No YubiKey, no trusted Wi-Fi, no iPad, no Polar license in this increment. Free download.
- **Source:** Fast path after market check (BLEUnlock, ProximityLock, Unlock exist). Wedge is lock-not-sleep, one-toggle UX, TenPrint catalog next to SessionGuard.
- **Landed in:** FR-2–FR-8, non-goals.

## 2026-08-31 — Competitors

- **Decision:** Ship anyway. Windows Dynamic Lock is native; macOS is not. Third-party Mac tools exist and are uneven. WalkAway is the polished, local, SessionGuard-paired option.
- **Source:** Ferenc: easy and still a gap he wants filled.
- **Landed in:** vision.

## 2026-08-31 — Sparkle deferred

- **Decision:** No auto-update in this increment. Distribution is a GitHub Release DMG. Catalog copy lives on tenprintsoftware.com.
- **Source:** Foundation PRD has no Sparkle FR. Keys and a product domain are not set up.
- **Landed in:** build_dmg.sh, TenPrint catalog.

## 2026-08-31 — Bluetooth off does not lock

- **Decision:** If the adapter is off, unauthorized, or unavailable, WalkAway does not evaluate presence and does not lock. Lost advertisements while Bluetooth is on still count as away.
- **Source:** Fast path while finishing FR-3.
- **Landed in:** `shouldEvaluatePresence`, addendum.
